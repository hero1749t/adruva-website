# Google Search Console (GSC) Integration Guide

This guide explains how to add, verify, and index **Adruva Solutions** in Google Search Console to monitor search traffic, request indexing of pages, and track Google rankings.

---

## Step 1: Add a Property in Google Search Console

1. Navigate to the [Google Search Console Dashboard](https://search.google.com/search-console).
2. Click the property dropdown in the top-left corner and select **Add Property**.
3. Choose one of the following verification types:
   - **Domain Property (Recommended):** Covers all subdomains and protocol variants (`http`, `https`, `www`).
   - **URL Prefix Property:** Covers only the specified URL path (e.g., `https://adruvasolution.com`).

---

## Step 2: Verification Methods

Depending on the property type chosen, verify ownership using one of the methods below:

### Option A: DNS TXT Record (Required for Domain Properties)

1. Copy the TXT verification record generated by Google Search Console (e.g., `google-site-verification=xxxxxx`).
2. Log in to your domain registrar (e.g., GoDaddy, Namecheap, Hostinger).
3. Navigate to the **DNS Settings / Zone Editor** page.
4. Add a new record:
   - **Type:** `TXT`
   - **Host/Name:** `@` (or leave blank)
   - **TXT Value:** _Paste the verification string copied from Google_
   - **TTL:** `3600` (or Default)
5. Save the record and wait a few minutes for propagation, then click **Verify** in GSC.

### Option B: HTML File Upload (For URL Prefix Properties)

1. Download the verification HTML file from the Search Console setup screen.
2. Upload this file to the root of your web server (into `/apps/web/public/` folder).
3. Commit and push the file to trigger a Vercel build so the file is accessible at `https://adruvasolution.com/google-site-verification-code.html`.
4. Click **Verify** in GSC.

### Option C: HTML Meta Tag (For URL Prefix Properties)

1. Copy the `<meta name="google-site-verification" content="..." />` tag.
2. Open [`apps/web/app/layout.tsx`](file:///D:/adruva-website/apps/web/app/layout.tsx) and add it to the page `<head>` or via Next.js metadata API:
   ```typescript
   export const metadata: Metadata = {
     verification: {
       google: "your-verification-code-here",
     },
   };
   ```
3. Deploy the changes and click **Verify** in GSC.

---

## Step 3: Submit Your Sitemap

Once verified, tell Google where to find your content:

1. In GSC, click **Sitemaps** on the left menu under the Indexing section.
2. Under "Add a new sitemap", enter your sitemap URL:
   - **Sitemap URL:** `sitemap.xml`
3. Click **Submit**.
4. Google will queue the sitemap. It should change status to **Success** within 24 hours.

---

## Step 4: Indexing and Optimization Tips

- **Inspect URL:** Use GSC's search bar to inspect individual page paths (e.g., `https://adruvasolution.com/services/web-development`) and check if they are indexed. If not, click **Request Indexing**.
- **Crawl Errors:** Monitor the **Coverage** section weekly to fix 404s, mobile usability warnings, or core web vitals alerts.
